# Swatches

A small page for looking at a color palette: names for each color, sample charts, optional snapping to nicer nearby colors, and color-blindness checks.

Put colors in the link after `#`, separated by dashes:

https://ceesem.github.io/swatches/#264653-2a9d8f-e9c46a-f4a261-e76f51

The colors live in the part of the link after `#`, which browsers never send to the server.

Color names come from [color-names](https://github.com/meodai/color-names) (MIT). The Tailwind snap palette comes from [Tailwind CSS](https://tailwindcss.com) v3 (MIT).
