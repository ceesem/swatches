# Swatches

A small page for looking at a color palette: names for each color, sample charts, optional snapping to nicer nearby colors, color-blindness checks, and a few built-in palettes and colormaps to start from.

Put colors in the link after `#`, separated by dashes:

https://csdashm.com/swatches/#264653-2a9d8f-e9c46a-f4a261-e76f51

The colors live in the part of the link after `#`, which browsers never send to the server.

Color names come from [color-names](https://github.com/meodai/color-names) (MIT). The Tailwind snap palette comes from [Tailwind CSS](https://tailwindcss.com) v3 (MIT). Built-in palettes come from [seaborn](https://seaborn.pydata.org) (BSD-3-Clause), [matplotlib](https://matplotlib.org), [CARTOColors](https://carto.com/carto-colors/) by CARTO (CC BY 4.0), and Okabe & Ito (2008).
